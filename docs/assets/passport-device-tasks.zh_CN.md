## 布局与数据保留

`sdkconfig.defaults` 选择 `partitions.suite.csv`。上游最小模板 `partitions.csv`
保留且不改动。应用布局如下：

| 区域 | 地址 | 大小 |
| --- | ---: | ---: |
| 原有 NVS | `0x9000` | `0x6000` |
| 原有 PHY | `0xf000` | `0x1000` |
| Factory 应用 | `0x10000` | `0x5b0000` |
| 加密待办配置 | `0x5c0000` | `0x3000` |
| 待办配置密钥 | `0x5c3000` | `0x1000` |
| 待办双槽缓存 | `0x5d0000` | `0x230000` |

每槽 `0x118000` 字节：一个提交头扇区、最多 200 条/1 MiB 记录，以及独立的
32 KiB 页面临时区。擦写非活动槽不接触活动槽或两个 NVS 分区。响应分块流式写入
临时区，释放 TLS 后才逐条解析。各页必须具有一致的快照版本、选择版本、来源时间、
总数和游标；校验 schema、只读标记、UTF-8 和字段上限。全量负载 CRC 和回读校验后
最后写提交头。重启时通过头和负载 CRC 选择最新有效代；候选写入中断或损坏时回退
另一有效槽。CRC 用于检错，不防恶意篡改。提交头写入为提交点；回执中断时，重启
可能恢复完整的新代。

默认 NVS 初始化失败时不再自动擦除 Wi-Fi/城市设置，待办存储故障也不会格式化
默认 NVS。授权升级前，应确认当前应用实际结束位置早于新配置/缓存区域。采用分段
bootloader/分区表/应用写入，另行审阅配置镜像。保留设置时不得使用填充的合并镜像
或全片擦除。配置保留和实际断电行为仍需设备验收。

## 私密令牌配置

使用已激活的 ESP-IDF 5.5.3 Python：

```text
python tools/configure-task-device.py --origin https://tasks.example.test --companion-config <private-config.json> --output <new-private-directory> --probe
```

工具复制 `device_token` 和可选 `completion_token`，检查两者互不相同且均不同于
管理员令牌，验证 HTTPS origin 和令牌语法，
可选探测只读 API，并生成 AES-XTS 加密 NVS 和新的密码学随机密钥镜像。不提供
`--companion-config` 时使用隐藏输入。工具不会刷写设备、覆盖已有输出目录或把令牌
放入命令参数。Windows 新目录只允许操作者/系统/管理员访问；POSIX 使用 0700/0600，
结束后删除临时明文 CSV。可选写令牌以 `write_token` 保存，读取令牌仍为只读。
清单仅记录地址和镜像哈希，不含凭据。两份镜像保持私密，
与固件/调试归档分开，在另行批准的 USB 写入前审阅。设置网站、二维码和普通 BLE
命令均不能配置此令牌，Nextcloud 凭据留在服务器。

镜像会替换整个待办配置及密钥分区。本次首次完成升级来自没有完成日志的已安装
阅读器，保留原 origin/读取令牌并增加写令牌。以后轮换凭据必须保留未同步的
`taskops` 记录；此生成器不是队列原地迁移工具。Wi-Fi/城市 NVS 和待办缓存位于
镜像范围以外，分区表不变。

这是由物理访问控制的开发配置边界。密钥仍在 Flash 中；**尚未实现**硬件 Flash
加密、安全启动、设备/所有者绑定、防物理提取或签名可信时间。单独加密 NVS 不提供
这些属性。待办缓存本身为明文。不改写 eFuse，不能用此路径存储 OTP 种子。

HTTPS 要求现有可信时间状态并校验证书包；禁止重定向，凭据仅走 Authorization
请求头，单次请求超时 10 秒，整轮下载期限 90 秒。天气与待办共用 TLS 所有权互斥锁。
认证拒绝保留缓存，并停止后续请求，直到修复配置并重启设备。取消和错误保留上一
活动代。后台任务不引用 UI 对象，页面计时器先于屏幕删除。

## 页面与新鲜度

也回到刷新。选中刷新后短按 OK 下载服务端已提交快照，选中任务后短按 OK 打开
详情；从详情返回时保留该任务选中项。操作、状态、错误及详情标签使用简体中文，
提供明确按键提示。
下载时短按 OK 请求取消，长按 OK 返回启动器。详情显示标题、状态、到期类型、转换后
和原始到期值、原时区、列表 ID、备注以及来源/设备时间。上下键滚动并切换 UTF-8
安全的备注分页；短按 OK 打开操作菜单，长按 OK 返回。循环任务、子任务和来源备注
截断均有标记。完成操作仅适用于所有者可写、非循环、无父任务且具有强 ETag 的普通
任务。缺少资格元数据的旧快照仍可阅读，需先刷新才能完成。Refresh 下载服务端当前
已提交缓存，不触发新的 CalDAV 抓取；伴随服务现在会在上次任务完成五分钟后
周期从 Nextcloud 更新该缓存，操作者仍可按伴随服务指南手动触发服务端刷新。

来源抓取时间与设备提交时间独立显示。离线、超过 24 小时、时间不可信、空列表、未
配置、认证失败、取消和存储错误均有可见状态，不丢弃有效缓存。
LVGL 使用 C 标准库分配后端，页面对象与网络共享 ESP-IDF 系统堆，取消独立静态
48 KiB 池的永久预留。页面栈先删除上一屏，再创建下一屏。天气和待办 TLS 仍串行
使用；请求/结果日志只记录堆大小、缓存条数、结果码和任务栈余量。堆碎片及界面/
网络共存仍需真机检查，包含较大的城市选择页和长待办详情。
动态待办文本使用
公开 Noto Sans SC 16 px、2 位灰度字体，含 21,393 个码位，覆盖 ASCII、标点、CJK
统一表意文字和全角字符，但不覆盖全部 Unicode。保留缺字占位；公开范围、来源和
许可见[字体记录](../../assets/fonts/README.zh_CN.md)。
