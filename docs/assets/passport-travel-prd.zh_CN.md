## 1 范围与设计决定

用户已确定：一份多合一固件；首批铁路、导游、打卡；省份按需下载；服务器程序和网页；Linux＋Docker Compose 部署；WebDAV 持久存储；三体时钟完成后成为默认首页；OTP 最后设计且必须有可在设备丢失后恢复的密钥备份。额度显示、助手控制、QQ 音乐、PPT 和 FIDO 不在当前设计。

本文提出以下首版默认值，均为待评审方案，不能描述为用户已确认或实测结果：单用户私有部署；服务器 SQLite 工作数据库及文件缓存；浏览器通过网页操作；设备 Wi-Fi 和 HTTPS 同步；江苏省虚构样本包；SoftAP 本地网页配网。框架和依赖版本在编码前核对，本文不指定某个尚未验证的软件版本。

D1 只做新界面、配网与绑定、小资源包、持久事件、网页同步和 WebDAV 恢复基础。D2 实现铁路；D3 实现导游和音频原型；D4 实现中国打卡。各阶段都形成可运行增量并单独分支；数据格式共享。D1 的测试内容查看和完成按钮不是完整导游或打卡成品。

全体首批需求达成前，不把真实铁路接口、动态字体加载或真实语音 AI 请求默认为已有能力。缓存文字是基础；缓存音频是 D3 必需验收能力，不能用“可选音频文件”长期替代它。语音追问在 D3 增量内单独测连接、限额、取消和答复，不影响离线游览。

## 2 一个完整使用流程

1. 用户部署服务器，在浏览器登录，配置 WebDAV 并测试目录读写与恢复；敏感配置不进入仓库。
2. 用户在设备进入配网页，用手机连接设备临时热点，在本地网页输入 2.4 GHz 网络和服务器 HTTPS 地址；凭据仅私下保存。
3. 网页创建短期绑定请求，用户把显示的绑定码输入本地配网页；设备连接服务器后，在设备确认账号绑定。网络连接、服务器认证与绑定分别显示。
4. 网页导入并审核车票，审核导游路线，选择省份和所需内容，发布版本；设备同步、显示大小、确认下载。
5. 下载完整校验后启用。离线查看乘车字段、下一站和讲解；确认城市去过或加入心愿单，设备先保存再反馈。
6. 重连后上传待同步事件。网页显示服务器已接收及 WebDAV 备份状态。用户可以删除资源腾出空间，历史保留。
7. 从 WebDAV 的完整快照恢复空白服务器；设备重新绑定后仍可同步。旧服务器的设备令牌不应在恢复时自动重新启用。

没有服务器或网络时，设备可直接进入已有离线内容；首次无资源也能查看全国摘要、设置和明确的空状态。

## 4 按键事件与取消

建议应用事件层产生 `PRESS`、`RELEASE`、`CLICK`、`HOLD_START`、`REPEAT`。确认键在按下后 700 ms 触发长按；触发长按后松开不再产生短按。上下键先移动一次，按住 450 ms 开始每 180 ms 连翻，超过 1.5 秒每 90 ms、超过 3 秒每 60 ms；节奏均为候选目标。普通列表到边界停止，不自动环回；首字母选择器可环回。

全局长按确认打开 P04。G24 为明确例外：进入录音页后显示“按住确认说话，松开发送”；待录音状态短按确认不发送，长按进入录音、松开提交；短按上键取消本轮并清理缓冲，短按下键返回 G22。没有进入 G24 前长按确认仍只打开菜单，因此语音与返回不会争用手势。录音最多 10 秒，达到上限自动停止并进入“确认发送”状态，此状态短按确认发送，上键取消、下键返回；上限停止后原按键松开不自动发送；录音不做大块 RAM 缓存。这个交互需要在 D3 真机验证。

搜索 C34 的字母和结果采用两个明确模式。上下选字母，确认追加；菜单选择显示结果后上下选结果、确认打开；菜单可退一字或返回字母模式。初始串最多 8 个 ASCII 字母，设备不承担完整中文键盘。县区搜索作用域显示为当前省，结果展示所属城市避免重名。

G22 默认是动作列表，选择“阅读讲解”进入页内文字模式；上下翻页，短按确认回动作列表，长按确认仍开 P04。G23 播放页上下选择暂停或继续、停止，确认执行。网络或下载页的取消先请求工作任务停止，确认停止后返回；保留可恢复的原资源。任意页面退出前，停止能访问该页面的任务、回调、计时器。忙碌期间仍响应取消，不叠加重复请求。

## 5 铁路需求

| 编号 | 必须具备的行为 |
| --- | --- |
| R01 | 网页先支持手动输入及粘贴文本导入；截图和文档上传可保存等待人工填写，OCR 后续适配，不虚报识别成功 |
| R02 | 字段级来源和确认状态；用户确认缺失或疑似字段后发布，允许明确的未提供值 |
| R03 | 设备展示票面全部必需字段，按乘车日期处理跨午夜，中途上车及无座文字 |
| R04 | 停站显示计划和实际时间类别，正确计算有日期的停站时长；用户乘车区间单独标注 |
| R05 | 车型仅在有可核实来源时显示；未知不会从 G、D 或其他字头推断 |
| R06 | 无车票时查看已配置站点的出发列表；计划列表和实时大屏明确区分 |
| R07 | 缓存显示获取时间及过期状态；无真实接口或无数据时明确说明，不生成假列车冒充实时来源 |

真实数据接入调查表如下；D0 没有取得实际账号或样本，不把它作为已完成能力。

| 字段 | 预期来源 | 当前证据与处理 |
| --- | --- | --- |
| 上下车站、车次、日期、座位、车厢 | 用户提供的 12306 内容，经人工确认 | 仅有虚构样本；真实格式待脱敏样本验证 |
| 途径站、到发时间、停站 | 合法可用的时刻表接口或用户资料 | 尚未选择接口；先用明确测试样本验证模型 |
| 车型 | 有车型字段且能对应日期和车次的数据源 | 未验证；未知明确留空 |
| 站台、检票口、检票状态、晚点 | 实际车站大屏数据源 | 未验证；不能用时刻表替代实时大屏验收 |

D2 可以完成导入和缓存界面后把实时接入单列为未验证项，但整个铁路需求不能据此报告全部完成。自动抓取方案须在编码前核查接口许可、认证、速率和字段，不能先假定存在稳定开放接口。

## 6 导游需求

| 编号 | 必须具备的行为 |
| --- | --- |
| G01 | 网页输入目的地、日期、可用时长、同行限制；可手动创建路线，AI 草案在服务可用后接入 |
| G02 | 草案、审核、发布为分开状态，重新生成建立新草案，不改已发布版本 |
| G03 | 多行程保存在服务器，网页选择同步内容；设备只保留容量允许的选定版本 |
| G04 | 包含 3 至 5 站样本的文字和音频；全部断网后仍能翻看、播放、暂停和取消 |
| G05 | 手动完成和撤销完成，显示进度；发布更新按稳定站点 ID 保留进度，删除站点保留历史 |
| G06 | 联网追问只用已选路线和当前站点上下文，语音过程有超时和取消；不覆盖审核路线 |
| G07 | 开放时间有来源和更新状态；无 GPS 自动判断和到站承诺，不保证 AI 建议对应实时开放情况 |

首个音频原型以一段不超过 15 秒的单声道 16 kHz 16 位 PCM 测播放链路，原始数据不超过 480,000 字节。这里只确定原型格式，不能作为完整讲解容量结论。D3 选择压缩格式并测 CPU、RAM 和音质，再冻结音频能力；如果不适合硬件，修改设计并评审，不能静默取消离线讲解。

## 7 中国打卡需求

| 编号 | 必须具备的行为 |
| --- | --- |
| C01 | 全国地图与 34 个省级行政区标识常驻；精确区块可读性和地图素材审核独立验收 |
| C02 | 设备选省下载，网页也可选包；展示覆盖、大小、版本、临时空间；失败不破坏旧包 |
| C03 | 按包内层级浏览，拼音首字母检索；首字母来自经审核数据，多音地名不由设备猜测 |
| C04 | 去过、想去为独立状态；确认后保存成功才播放盖章反馈；更新和删除资源不删记录 |
| C05 | 首次城市足迹产生城市印章和短动画；本地掉电重启后仍保留 |
| C06 | 景点确认去过归属城市，市确认去过点亮省；撤销最后一条贡献后重算摘要，直接确认城市记录仍计入 |
| C07 | 34 个省级区均有有效足迹后全国足迹成就点亮；撤销后如不满足则撤回，历史解锁另存 |
| C08 | 今日一景、精选、印章册、足迹、心愿、成就和设置；离线用已缓存候选，日期未知则不伪造今日内容 |

城市印章区分当前有效和历史获得；撤销最后有效城市足迹后地图熄灭，印章历史保留并标记无当前足迹。重复事件不重复盖章，重新确认去过可重播短反馈但不重复记印章历史。记录按地点稳定 ID 保存，不依赖当前资源包存在。省级直接去过操作若后续需要，须另行定义；首版先通过城市或景点贡献点亮省份。一个城市可同时处于去过及想再去状态，网页解释两个独立标签。服务器数据升级若更换 ID，必须提供映射或保留旧记录，不能把名称当唯一身份。

## 9 连接与配网设计

建议 D1 使用限时 SoftAP 本地网页，不依赖浏览器 BLE。只有用户在设备确认进入配网才开放临时热点；使用每次生成的口令，显示本地地址，五分钟超时或取消后停止。只接受本地配网会话的设置；限制请求大小、频率和来源，并设计防止跨站请求的校验。服务器浏览器页不自动跨域控制本地设备。SSID 和口令不写日志，成功后停止配网页，保留此前可用设置直到新连接验证。

SoftAP 是新增应用能力。[ESP-IDF 5.5.3 配网文档](https://docs.espressif.com/projects/esp-idf/en/v5.5.3/esp32c3/api-reference/provisioning/wifi_provisioning.html)提供 SoftAP 和 BLE 传输，但网页客户端和安全握手并不是基线已实现功能。D1 在实现前选择使用配网管理器加兼容网页客户端，或受限的应用本地设置服务，并说明认证和机密传输边界；不能复制示例中的密码日志。若浏览器方案实测不可行，再评审 BLUFI 小程序替代，不默默新增原生应用依赖。

绑定码由已登录网页生成，建议有效期五分钟、单次兑换、限制失败次数；长度及随机性在安全评审时确定。设备先验证 HTTPS 服务器，再兑换绑定请求，显示账户标签并要求实体确认，完成后取得仅限该设备的可撤销凭据。配网口令、绑定码和设备令牌互不替代。生产 HTTPS 校验域名和信任链。建议配网页由用户确认浏览器提供的日期时间，标为 user_set，用于初次 TLS 校验；设备随后从已认证服务器取得 server_time 并标记校时。时间不合理或证书无效则停止联网并提示重新校时，不忽略证书有效期。该时间引导需在 D1 验证，不等于已解决最后 OTP 阶段的时间信任。

建议同步默认手动；活动同步页最多每 30 秒轮询一次，休眠期间停止轮询；失败指数退避且不快速循环。录音播放时推迟大下载。具体超时和缓冲见第一版约定，仍需实测。

## 10 离线与数据保存状态

| 情况 | 设备行为 | 网页与服务器行为 |
| --- | --- | --- |
| 无 Wi-Fi 或服务器不可达 | 查看缓存、打卡、完成路线，本地保存；联网追问明确不可用 | 显示最后已知同步状态，不能宣称设备已接收发布 |
| 下载中断或校验失败 | 旧包继续可用，新包未启用；可取消后重试 | 保留对应不可变版本，显示错误和队列状态 |
| 事件已本地保存但未确认 | 待同步数量增加，重启保留 | 未接收时不显示已同步 |
| 服务器可靠接收但 WebDAV 失败 | 可以清除已确认的事件队列，但显示远端备份待完成 | 本地记录和上传任务可靠保留；提示未完成远端持久化 |
| WebDAV 失联或配额不足 | 设备已有内容正常；未缓存远端资源下载可能失败 | 本地查询可用，上传退避；本地也满则拒绝无法可靠保存的新内容 |
| 空白服务器恢复 | 离线设备保留本地记录，重绑定后校对差异 | 只恢复完整快照，先验证摘要和版本，恢复为新实例；待上传数据不在快照内 |
| 遗失设备 | 已有备份可用于恢复，尚未同步记录可能丢失 | 撤销服务器令牌；未来 OTP 用独立恢复材料取回加密备份，必要时更换账号种子 |

删除缓存与删除个人记录分开操作，均明确后果。修正同步冲突不是简单按设备时间取最新。设备解绑不自动擦内容，也不等同于 OTP 密钥作废。真实记录保存前必须批准数据迁移和刷写保存策略。

## 11 样本和资源原型

样本名称为 `fixture-js-trip-001`；省份标识 `CN-JS`，城市“苏州市”，县区“测试区”，景点“甪直字形测试点”等全部作为功能样本，不代表真实行政目录、景点或旅行建议。地图常驻全国结构，D1 只下载小样本，D4 才验收完整省包交互。所有界面显示“测试数据”。

虚构车次 `TEST-001`，始发站“样本站 A”，用户在“样本站 B”上车，2026-10-03 23:58 发车，“样本站 C”2026-10-04 00:20 到、00:25 发，“样本站 D”01:00 下车；样本车厢 02、座位 03A，车型未知。站 C 停站五分钟。它只验证跨日和中途上车，不对应实际车次。

导游站点 `stop-001` 至 `stop-003` 使用虚构讲解和一段 15 秒以内音频。一个城市、一个县区、三个景点含首字母和字形负例；不承诺这个样本已制作成可运行资源或音频文件。编码时生成真实摘要和字体清单，不能使用假的散列跳过校验。

D1 需测完整包大小、应用大小、最低堆、最大连续块、任务栈、TLS 峰值与退出后基线。D3 增加音频耗时和供给间隔。拟议 Flash 分类预算沿用总体规划，不提前写分区表。D1 样本包上限 768 KiB，设备是否能留存由空间预检决定。实验布局详见数据约定：5 MiB 应用、128 KiB 记录 NVS、两槽共 2.8125 MiB 资源 FAT；这是 D1 原型方案，未修改现有分区表，不是最终多合一容量承诺。
