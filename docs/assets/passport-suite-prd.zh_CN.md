## 4 新 UI 与通用输入规则

D/V：采用简洁纵向布局：状态条（电量在右上，不可读显示横线）、大内容区、固定底部按键提示、独立全屏票码。首页用程序场景，不继承 demo 卡片/吉祥物/云朵；功能入口为单列文字。详情为可滚动的标注字段，清晰显示来源与时效。不使用旧菜单/页面/ui_pixel 创建函数。避开圆角，票码画布为居中 216 × 216 安全方形。

仅独立使用 UP/DOWN/OK，CLICK 对应短按。PRESS 建立应用手势代次；LONG 消耗该代次，打开操作菜单（忙时按下文取消），并抑制同次按压后续所有 CLICK/DOUBLE，直到新 PRESS。DOUBLE 不执行动作；测试快速双击，不虚构松开事件。输入携带按键、手势 ID、单调时间和页面代次。若现有组件事件顺序无法证明，ST-01 必须先解决；按住录音需另行评审 BSP RELEASE 扩展及主机/真机测试，不用 ADC 推断松开。

操作菜单：上下选择，OK 执行；长 OK 关闭菜单回来源页。返回始终首项。破坏性/远端操作打开 是/取消 确认页，默认选取消；上下选择，OK 仅提交一次，长 OK 取消。其余场景 UP/DOWN 长按无动作。长 OK 引发换页后不能再触发新页 OK。

输入队列建议深度 16，合并普通移动事件；队列满显示忙并丢弃导航，不重复动作。取消/停止用独立原子标志或 worker 通知，避免被满队列吞掉；丢事件前仍保留 LONG 消耗标记。持久操作仅在日志队列接纳后算接受；完成操作队列满显示未保存，不能显示待同步。生命周期所有权见 SC-04。

## 6 状态、所有权与故障呈现

| 状态类 | D/V 行为与安全退出 |
| --- | --- |
| 每页进入/就绪/退出 | 从验证后的不可变模型进入；退出先失效页面代次，再停页面 worker/timer/订阅；收到停止确认后才删除对象 |
| 加载 | 显示阶段和耗时，可取消，OK 不重复提交；已有缓存单独标注 |
| 离线 | 票夹/待办显示完整缓存版本与时间；完成可排队；翻译不可开始；可信 OTP 可工作到时间误差上限；天气保留过期数据 |
| 空 | 无票/无任务/无账户/未选集合分别说明并给网页或导入指引，仍可返回 |
| 错误 | 安全原因及重试/返回；区分密码/TLS/认证/时间/资源错误，不展示秘密 |
| 过期/冲突 | 显示时效及本地远端差别，保留可用版本和较新远端数据，不静默覆盖 |
| 队列满/停止超时 | 显示忙/未保存；取消标志仍有效。worker 仍可能访问 UI 时保留页面，允许重试停止，不删除 |

页面所有者拥有 LVGL 对象、场景 timer、录制/播放作业、视图订阅。后台同步协调者拥有 Wi-Fi 重连、票据/待办缓存、持久完成队列、天气刷新。退页取消页面音频作业，不取消已经持久接纳的待办完成意图。后台服务不得持有原始 LVGL 指针：向 UI 所有者发送带请求 ID/页面代次的模型，退出及取消后拒绝迟到回调。跨任务 LVGL 使用 `bsp_lvgl_lock()`，回调只入队。阶段时限和缓存时效见 SC-03/06/07/08/10。
