# Travel application fonts

Generated subsets for the D1 travel UI (`main/passport/`). Generated files:

- `travel_font_16.c`, `travel_font_20.c` — LVGL font data (bpp 4, uncompressed)
  for sizes 16 px and 20 px, generated by `tools/gen_passport_fonts.py`.
- `travel_glyph_inventory.json` — machine-readable coverage list consumed by
  host tests and the device-side activation glyph check.

## Regeneration

```bash
PASSPORT_FONT_SOURCE=assets/fonts/NotoSansSC.otf \
  PATH="$(npm --prefix <workdir> bin):$PATH" \
  python3 tools/gen_passport_fonts.py
```

The canopy (UI strings plus companion fixture content) drives coverage;
negative-control code points U+2A302 and U+3FFFF must stay absent from the
generated data; the host test fails if they appear.
